# Расписание студента (Android, Kotlin)

Приложение по макету `student_schedule_mobile_figma.html`.

## Запуск
1. Android Studio Koala (2024.1) или новее, JDK 17 (встроенный JBR подходит).
2. File → Open → папка `Lab4_UI_Components`. Дождаться Gradle Sync
   (Gradle 8.7 и зависимости скачаются автоматически).
3. Запустить на эмуляторе/устройстве с Android 8.0+ (API 26+).

Если нужен `gradlew` для консоли: `gradle wrapper --gradle-version 8.7` (один раз).

## Что внутри
- **Room**: занятия, задачи, новости, история уведомлений.
- **Navigation + Fragments + ViewBinding**, нижняя навигация (Главная / Расписание / Задачи / Профиль).
- **Расписание**: недельный шаблон, занятия генерируются на 4 недель вперёд и подгружаются автоматически.
- **Задачи**: добавление, редактирование, выполнение (чекбокс), удаление (долгий тап или кнопка + диалог), группы «Просрочено / Сегодня / Завтра / Позже / Выполнено», пустое состояние.
- **Напоминания** (WorkManager): за 15 минут до занятия и до срока задачи; учитывают переключатели в настройках, звук и вибрацию. Запрос разрешения POST_NOTIFICATIONS на Android 13+.
- **Настройки**: тёмная / автоматическая тема, уведомления, звук, вибрация, проверка уведомления.
- **Профиль** редактируется (имя, группа, курс, специальность); приветствие на главной берёт имя из профиля.
- Новости, история уведомлений, экран синхронизации (skeleton-загрузка).

При первом запуске создаются демо-данные (4 задачи, 3 новости).
